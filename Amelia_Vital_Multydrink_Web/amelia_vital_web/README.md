# Amelia Vital — Multidrink

Página web vertical desarrollada con HTML5 + Bootstrap 5 + CSS + JavaScript.

## Estructura

- Header / navegación
- Introducción / Hero
- ¿Qué es?
- ¿Para qué sirve?
- Ingredientes
- Conocer / Comprar
- Testimonios / Comprar
- Registros / Certificados
- Formulario de contacto
- Pie de página

## Archivos

- `index.html`
- `styles.css`
- `script.js`
- `assets/multydrink-referencia.png`

## Cómo ejecutarla

Abre `index.html` directamente en el navegador.

También puedes usar Live Server en VS Code para verla con recarga automática.

## Personalización

La paleta principal está definida en `styles.css`:

- Borgoña: `#6F1D35`
- Verde oliva: `#788B32`
- Crema: `#F8F5EA`
- Borgoña oscuro: `#521426`

### Importante

La imagen incluida es la referencia proporcionada para el diseño. Para una versión comercial, reemplaza `assets/multydrink-referencia.png` por fotografías oficiales del producto y reemplaza los textos de beneficios, testimonios, registros y certificados por información verificada del fabricante.
